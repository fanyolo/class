说明



gui文件夹中是完整的程序

报告最后程序清单有对文件的说明

| **文件名**                      | **作用描述**                                                 |
| ------------------------------- | ------------------------------------------------------------ |
| **append_to_input.m**           | 将按键添加到输入框中，更新输入框内容。                       |
| **delete_last_character.m**     | 删除输入框中的最后一个字符，用于模拟拨号时的删除操作。       |
| **detect_key_using_bandpass.m** | 使用带通滤波器法识别拨号音的频率，进而推断按键值。           |
| **detect_key_using_goertzel.m** | 使用Goertzel算法识别拨号音的频率，进而推断按键值。           |
| **goertzel.m**                  | 实现Goertzel算法，用于计算信号中特定频率的功率谱。           |
| **gui.m**                       | 图形用户界面（GUI）主文件，负责构建和管理界面，处理用户交互。 |
| **play_and_save_dtmf.m**        | 播放生成的DTMF拨号音并保存为音频文件。                       |
| **play_dtmf.m**                 | 播放生成的单个拨号音，模拟按键按下的声音。                   |
| **plot_waveform.m**             | 绘制拨号音的时域波形和频域波形图，用于可视化分析信号的特性。 |
| **recognize_dtmf.m**            | 根据输入的DTMF信号估计频率并识别对应的按键值，结合两种识别算法。 |
| **recognize_dtmf_wav.m**        | 读取.wav文件，识别其中的DTMF信号，并输出识别的按键值。       |
| **update_input.m**              | 更新输入框中的内容，用于处理用户在GUI中输入的按键数据。      |
